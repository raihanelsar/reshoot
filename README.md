# 🎞️ Reshoot

**Reshoot** adalah proyek berbasis **frontend** yang dirancang untuk menampilkan antarmuka interaktif dalam proses **pengambilan ulang (reshoot)** atau **pengolahan gambar sederhana**.  
Aplikasi ini dikembangkan menggunakan teknologi web modern dengan fokus pada tampilan yang bersih dan responsif.

---

## 🧩 Fitur Utama

- 📸 Upload dan tampilkan gambar  
- 🔁 Reshoot / refresh tampilan foto  
- 🖼️ Preview hasil gambar dengan antarmuka sederhana  
- 💻 Responsif dan dapat diakses di berbagai perangkat  
- ⚡ Performa ringan karena hanya berbasis frontend  

---

## 🛠️ Teknologi yang Digunakan

- **HTML5** – struktur halaman  
- **CSS3 – styling modern dan responsif    
- **Git & GitHub** – versi kontrol dan hosting proyek  

---

# 1. Clone repository
